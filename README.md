## Service
### OrderService
- 기능 구현
    - [ ] 프로모션 날짜 안에 현재 날짜가 잇는지 확인
    - [ ] 프로모션 상품이 있는 상품인지 확인
    - [ ] 프로모션 계산 : 프로모션 먼저 깎아야 한다
      - [ ] 1. buy + get으로 나누면 프로모션 단위
      - [ ] 2. 전체에서 나눈거랑 프로모션에서 나눈 단위 (가능단위) 중 작은게 적용 단위
      - [ ] 3. 2 * 1 이 프로모션 전체 구매 금액
      - [ ] 4. 전체 - 3이 일반 적용 금액
    - [ ] 일반 계산 : 프로모션 상품 없을 경우 & 프로모션 기간 지남
    - [ ] 재고 차감 및 주문 저장하는 기능
    - [ ] 구매 상품 리스트 가져오는 기능
    - [ ] 증정 상품 리스트 가져오는 기능
    - [ ] 총 구매액 계산하는 기능
      - [ ] 전체 order 금액 프로모션 상관없이 더하기
    - [ ] 행사 할인금 계산
      - [ ] 총 제공 상품의 금액 더하기
    - [ ] 멤버십 할인
      - [ ] Y선택시 총 구매액에서 * 0.7
- 예외 처리
    - [ ] 일반 계산시 수량보다 적으면 에러
    - [ ] 프로모션 계산시 전체 수량보다 적으면 에러
    - [ ] 존재하지 않는 상품일 경우 에러

## Controller
### OrderController
- 기능 구현
    - [ ] 더 받을 수 있는 프로모션이 있는지 확인하기 (확인 메서드)
    - [ ] 구매한 것을 buy + get으로 나눈 나머지가 buy일 경우, 
      - 근데 이제 여기서 받은 재고보다 남은게 커야한다.
    - [ ] 프로모션 할인 적용 불가인 것 안내하기
      - 입력 받은 결과물로 출력하기
    - [ ] 전체 로직 계산
    - [ ] 상품 list, 증정 상품 list, 총 구매액, 행사 할인금, 멤버십 할인 금, 총 낼 돈을 필드로 만들어서 dto에 담기
- 예외 처리
    - [ ] service에서 오는 예외들 받아서 분기처리, >> 입력 관련 에러는 다시 input으로 보내기
