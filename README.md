# 미션 : 편의점 - 구현 기능 정리

## View
### InputView
- [ ] 구매 상품명과 수량을 입력 받는 부분
- [ ] 프로모션 받을 수 있는 경우 print
- [ ] 프로모션 할인 받을 수 없는 경우 print
- [ ] 추가 상품 구매 여부 입력 받기
- 예외 처리
    - [ ] 기타 잘못된 입력의 경우 

### OutputView
- [ ] 초반 인사말
- [ ] 재고 상품 출력
- [ ] 영수증 출력 : 증정, 행사 할인, 멤버십 할인, 총 금액 으로 나눠져 있다.

## Util
### InputParser
- 기능 구현 
    - [ ] 입력 받은 상품과 수량을 쪼개서 list로 만든다.
    - [ ] List<List> 형식으로 받는다.
- 예외 처리
    - [ ] 구매할 상품과 수량 형식이 올바르지 않은 경우 : [사이다-2], ....
    - [ ] 입력한 재고의 숫자가 0일 경우

### InitData
- 기능 구현
  - [ ] md 파일을 file로 받아와서 이걸 가지고 객체 생성, repo에 저장해야 한다.

## Service
### OrderService
- 기능 구현
    - [ ] 해당 상품이 프로모션 상품인지 판단하는 기능
    - [ ] 해당 상품이 프로모션 상품인데 수량이 다 적용 되었는지 판단하는 기능
    - [ ] 상품 재고 깎는 기능
    - [ ] 프로모션 상품 재고 판단하는 기능
    - [ ] 주문에서 삭제하는 기능
    - [ ] 주문 추가하는 기능
    - [ ] 상품 재고 깎는 기능
    - [ ] 상품 재고 추가하는 기능
- 예외 처리
    - [ ] 존재하지 않는 상품을 입력한 경우
