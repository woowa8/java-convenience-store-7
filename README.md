## Service
### OrderService
- 기능 구현
    - [x] 프로모션 날짜 안에 현재 날짜가 잇는지 확인
    - [x] 프로모션 상품이 있는 상품인지 확인
    - [x] 프로모션 계산 : 프로모션 먼저 깎아야 한다
      - [x] 1. buy + get으로 나누면 프로모션 단위
      - [x] 2. 전체에서 나눈거랑 프로모션에서 나눈 단위 (가능단위) 중 작은게 적용 단위
      - [x] 3. 2 * 1 이 프로모션 전체 구매 금액
      - [x] 4. 전체 - 3이 일반 적용 금액
    - [x] 일반 계산 : 프로모션 상품 없을 경우 & 프로모션 기간 지남
    - [x] 재고 차감 및 주문 저장하는 기능
    - [x] 구매 상품 리스트 가져오는 기능
    - [x] 증정 상품 리스트 가져오는 기능
    - [x] 총 구매액 계산하는 기능
      - [x] 전체 order 금액 프로모션 상관없이 더하기
    - [x] 행사 할인금 계산
      - [x] 총 제공 상품의 금액 더하기
    - [x] 멤버십 할인
      - [x] Y선택시 총 구매액에서 * 0.7
- 예외 처리
    - [x] 일반 계산시 수량보다 적으면 에러
    - [x] 프로모션 계산시 전체 수량보다 적으면 에러
    - [x] 존재하지 않는 상품일 경우 에러
